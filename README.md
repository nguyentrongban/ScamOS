# SCAMOS

SCAMOS is a mobile-first 3D web game built with React, Vite and Three.js.

## Controls
- Mobile / iPhone / Android: touch joystick + action buttons.
- iPad: touch joystick with tablet-friendly controls.
- Desktop: WASD / arrow keys + mouse/keyboard.

## Run
npm install
npm run dev

## Build
npm run typecheck
npm run build

Designed for Vercel deployment. All player-facing content is Vietnamese.
